# Beam Project

A responsive folder-management dashboard implemented from the Rhino Labs Figma design. The prototype includes folder navigation, file previews, uploads, downloads, copy-link actions, folder creation, and local dummy content for interactive states.

## Tech stack

- React 18
- TypeScript
- Vite
- CSS

## Local development

Requirements: Node.js 18 or newer and npm.

```bash
npm install
npm run dev
```

The development server runs at [http://127.0.0.1:5173](http://127.0.0.1:5173) by default. If that port is occupied, Vite selects the next available port.

## Production build

```bash
npm run build
```

The generated production files are written to `dist/`. This directory and installed dependencies are intentionally excluded from Git.

## Repository

The local repository is connected to:

https://github.com/stevelauda25/Beam-Project.git
